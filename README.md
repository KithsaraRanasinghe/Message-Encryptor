# Message-Encryptor-
A simple Python-based message encryption and decryption program using the Caesar Cipher technique.

Features
  -Encrypt messages using a shift number.
  -Decrypt encrypted messages using the same shift number.
  -Preserves spaces and special characters.
  -Supports continuous encryption and decryption until the user exits.

How to Run
1. Download and extract the repository file:
2. Open the message-encryptor.py file from any python editor.
3. Run the code.
